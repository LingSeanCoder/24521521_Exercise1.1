## AI Usage Boundary

### AI Responsibilities

AI is used for:

- Requirement analysis
- Task decomposition
- Semantic HTML recommendations
- Accessibility explanations
- Skip-link implementation guidance
- Code review
- Git commit message suggestions

### Human Responsibilities

The student is responsible for:

- Reviewing AI-generated suggestions
- Writing and integrating the final implementation
- Running the website locally
- Testing the skip link
- Verifying the accessibility landmark tree
- Reviewing the final result
- Creating the Git commit
- Pushing the final work to GitHub
